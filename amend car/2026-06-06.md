## build.bat 空格路径修复

问题现象：

- 构建时 GCC 报错：
  - `arm-none-eabi-gcc.exe: error: car\2026-06-06_2026v1_first_version\compiler/includeRTOSE7: No such file or directory`
  - `arm-none-eabi-gcc.exe: error: D:\amend: No such file or directory`
  - `arm-none-eabi-gcc.exe: fatal error: no input files`

原因判断：

- `D:\amend car` 路径中包含空格。
- 原 `build.bat` 中 `-I%path_lib%`、`%path_src%`、`%path_out_name%.o` 等参数没有加引号。
- CMD 将 `D:\amend car\...` 拆成 `D:\amend` 和 `car\...`，导致 GCC 找不到路径。

处理方式：

- 将 `build.bat` 改为纯 ASCII 脚本，避免中文批处理注释编码影响 CMD 执行。
- 给工具链路径、库路径、源文件路径、输出文件路径、链接脚本路径全部加引号。
- 将链接脚本路径明确为 `compiler\includeRTOSE7\o\STM32H743ZITX_FLASH.ld`。
- 将等待 E7-RCU 磁盘时使用的 `timeout` 改为 `%SystemRoot%\System32\ping.exe`，避免 PATH 中找不到 `timeout`。
- 若 30 秒内未找到 E7-RCU 磁盘，脚本提示构建完成但未复制固件。
